## 3. 根因

- 拆分提交 **`b9182b8`**（2026-10-04，「D17 WorkbenchApp 拆分——index.tsx 5725 → 1972」）按区域切文件。文件夹弹窗在拆分前位于 `src/client/index.tsx:2942-2975`（`wb-modal` + 输入框 autoFocus + Enter 提交 + 遮罩取消 + 创建/保存按钮），**不在**提示层的搬迁区间（`index.tsx:845-1001`），也不属于点子详情区的三分支之一 ⇒ 没有任何新文件接手它。
- 后果：`useIdeas` 一侧的 `folderForm` / `patchFolderForm` / `saveFolder` 全部完好（类型、状态、POST/PATCH 都在），但**只有写、没有读**。点击时状态真的变了、没有任何组件渲染、没有任何请求、也没有任何报错。
- 判据为什么没拦住：`docs/tasks/8e5ea61d-…-D17客户端拆分/migration-matrix.md:64` 用「入口 **0 命中** `folderForm`」这种**负向**判据（渲染层整块消失时它照样通过），同文档 :80 还写了"文件夹弹窗整块逐字搬迁"。组件测试给的是 `onCreateFolder: () => {}` 桩，接线测试只断言"回调被传给了组件"。
- 影响版本：`v1.16.3` / `v1.16.4` / `v1.16.5` / `v1.17.0`（`git tag --contains b9182b8`）；`v1.16.2` 正常。
